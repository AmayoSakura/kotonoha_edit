# 言ノ葉Editer

**言ノ葉Editer** は、ブラウザ上でリアルタイムに日本語の本格的な組版（縦書き・横書き）を確認しながら文章を執筆し、そのまま高品質な印刷やPDF出力が行えるWebベースのテキストエディタ・自動組版ツールです。

小説や同人誌、原稿、エッセイなどの執筆から版組み・PDF化までをブラウザのみで完結できます。

## 🌟 主な特徴

### 📖 本格的な日本語自動組版
* **縦書き・横書き切り替え**: 日本語特有の縦書き（右綴じ）にワンクリックで対応。
* **柔軟な用紙・段組設定**:
  * 用紙サイズ: A4 / B5 / A5 / B6 / A6 / ハガキ
  * 段組: 1段組 / 2段組（境界線の有無指定可）
  * のど（綴じ代）や余白幅の調整
* **文字・書体設定**:
  * Shippori Mincho（しっぽり明朝）、Noto Serif JP、さわらび明朝、システム標準明朝に対応。
  * カスタムWebフォント（Google Fonts等）のURL指定にも対応。
* **ヘッダー・ノンブル（ページ番号）カスタマイズ**:
  * 表示条件（全ページ、奇数/偶数のみ、1ページ目を隠す等）
  * 表示位置（左右交互・中央・左右指定）
  * 数字タイプ（算用数字 `1, 2, 3...` / 漢数字 `一, 二, 三...`）および各種装飾（ハイフン、括弧、P.N等）

### ✍️ 快適な執筆・編集機能
* **リアルタイムプレビュー**: 本文を入力すると自動的にページ分割されてプレビューに即座反映。
* **ファイル入出力**: `.txt` および `.md` ファイルの読み込み（インポート）と保存（エクスポート）に対応。
* **便利ツール**: 文字数リアルタイムカウント、手動改ページ挿入、サンプル文章表示機能。

### 🖨️ 印刷 & PDF出力
* **Web Print対応**: 印刷ダイアログを起動し、ブラウザの標準機能（「PDFに保存」等）を用いてそのまま入稿・保存用のPDFを作成可能。

### 📱 レスポンシブ & カラーテーマ
* **カラーテーマ**: ライト ☀️ / ダーク 🌙 / セピア ☕ を選択可能。
* **モバイル最適化**: スマホ・タブレット表示時に「編集」「プレビュー」「両方」の画面切り替えタブを提供。

## 🚀 使い方

1. `index.html` をブラウザで開きます（サーバー不要で動作します）。
2. 左側の「✍️ 本文入力」タブで文章を入力・編集します。
3. 「⚙️ 組版・表示設定」タブで書字方向・用紙サイズ・フォント・ノンブルなどを自由に調整します。
4. 右側のプレビューエリアで仕上がりを確認します。
5. 「🖨️ 印刷 / PDF保存」ボタンを押すと、印刷プレビュー（またはPDF保存）画面が開きます。
