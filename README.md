# 言ノ葉Editer (v0.18)

**言ノ葉Editer** は、ブラウザ上でリアルタイムに日本語の本格的な縦書き組版を確認しながら文章を執筆し、そのまま高品質な印刷やPDF出力が行えるWebベースのテキストエディタ・自動組版ツールです。

小説や同人誌、原稿、エッセイなどの執筆から版組み・PDF化まで、サーバー不要・完全フロントエンド（ブラウザのみ）で完結できます。

---

## 🌟 主な特徴

### 📖 本格的な日本語自動組版エンジン
* **Canvas実測による高精度レイアウト**: 
  フォントの縦書き字送りや約物（「」など）固有のアキ、コードブロックのサイズ調整を考慮し、ミリ単位で精緻な自動ページ分割・組版を行います。
* **禁則処理 & 段落制御**:
  * 行頭・行尾禁則処理に対応。
  * かぎ括弧（`「`など）で始まる会話文の自動字下げスキップ。

### ✍️ 充実した執筆用記法 (Markdown + 独自拡張)
* **ルビ（ふりがな）**: `｜漢字《かんじ》` または `漢字《かんじ》`
* **傍点（圏点）**: `《《強調したい文字》》`
* **縦中横 (TCY)**: 半角数字（1〜2桁 `12`）や、感嘆符・疑問符の組み合わせ（`!?`, `?!`, `!!`, `??`, `！？`, `？！`, `！！`, `？？`）を自動縦中横化。
* **段落の配置指定**: 行頭に `[中央]` または `[center]`（中央寄せ）、`[右]` または `[right]`（右寄せ/下寄せ）。
* **標準Markdownサポート**: 見出し（`#`〜`######`）、太字（`**`）、斜体（`*`）、インラインコード（`` ` ``）、引用枠（`>`）、水平線（`---`）。
* **手動改ページ**: 行頭に `[改ページ]` または `<!-- pagebreak -->` と入力して任意の位置で改ページ。

### ⚙️ 柔軟な用紙・段組・レイアウト設定
* **用紙サイズ**: A4 / B5 / A5（標準） / B6 / A6 / ハガキ
* **段組設定**: 1段組 / 2段組（境界実線のあり・なし切替対応）
* **文字・余白・のど調整**:
  * 本文文字サイズ: 小 (8.5pt) / 標準 (9.5pt) / 中 (10.5pt) / 大 (12pt)
  * 余白: 狭い / 標準 / 広い
  * 綴じ代（のど）: あり（奇数・偶数ページで左右交互配置） / なし
* **豊かな書体（フォント）対応**:
  * Shippori Mincho（しっぽり明朝・標準） / Noto Serif JP / さわらび明朝 / システム標準明朝
  * **カスタムWebフォント**: 任意のGoogle Fonts等のCSS/Font URLとfamily名を指定可能。

### 📑 柱（ヘッダー） & ノンブル（ページ番号）設定
* **柱（ヘッダー）**: 表示条件（全ページ / 奇数 / 偶数 / 左右交互）、位置（右上 / 中央上 / 左上）、文字サイズ設定。
* **ノンブル（ページ番号）**: 
  * 表示条件（全ページ / 1ページ目非表示 / 完全非表示）
  * 形式（`- 1 -`, `P.1`, `/ 1 /`, `数字のみ`）
  * 位置（中央下 / 右下 / 左下 / 左右交互）
  * 開始ページ番号の任意指定。

### 🖨️ 高品質な印刷 & PDF出力
* **Web Print対応**: 画面右上の「印刷・PDF出力」ボタンから、ブラウザの標準印刷ダイアログを起動。全ページをプレビュー通り一括レンダリングして縦書きPDFとして保存可能。

### 📱 快適な編集UI & 自動保存
* **カラーテーマ**: セピア ☕ (標準) / ライト ☀️ / ダーク 🌙
* **自動保存 (LocalStorage)**: 執筆中の本文や各種設定が自動的にブラウザに保存され、再訪問時に即座に復元。
* **ファイル入出力**: `.txt` および `.md` の読み込み（インポート）と、タイトル名での `.txt` 保存（エクスポート）。
* **便利機能**: リアルタイム文字数カウント、手動改ページ挿入、一括全消去、サンプル文章自動セット。

### 📖 本格的な日本語自動組版
* **縦書き・横書き切り替え**: 日本語特有の縦書き（右綴じ）にワンクリックで対応。
* **柔軟な用紙・段組設定**:
  * 用紙サイズ: A4 / B5 / A5 / B6 / A6 / ハガキ
  * 段組: 1段組 / 2段組（境界線の有無指定可）
  * のど（綴じ代）や余白幅の調整
* **文字・書体設定**:
  * Shippori Mincho（しっぽり明朝）、Noto Serif JP、さわらび明朝、システム標準明朝に対応。
  * カスタムWebフォント（Google Fonts等）のURL指定にも対応。

  * 表示条件（全ページ、奇数/偶数のみ、1ページ目を隠す等）
  * 表示位置（左右交互・中央・左右指定）
  * 数字タイプ（算用数字 `1, 2, 3...` / 漢数字 `一, 二, 三...`）および各種装飾（ハイフン、括弧、P.N等）

### ✍️ 快適な執筆・編集機能
* **リアルタイムプレビュー**: 本文を入力すると自動的にページ分割されてプレビューに即座反映。
* **ファイル入出力**: `.txt` および `.md` ファイルの読み込み（インポート）と保存（エクスポート）に対応。

### 🖨️ 印刷 & PDF出力
* **Web Print対応**: 印刷ダイアログを起動し、ブラウザの標準機能（「PDFに保存」等）を用いてそのまま入稿・保存用のPDFを作成可能。

### 📱 レスポンシブ & カラーテーマ
* **カラーテーマ**: ライト ☀️ / ダーク 🌙 / セピア ☕ を選択可能。

## 🚀 使い方

1. `index.html` をブラウザで開きます（サーバー等の特別な準備は不要です）。
2. 「✍️ 本文入力」タブで表題・柱・本文を入力します。
3. 「⚙️ 組版・設定」タブで用紙サイズ・段組・フォント・ノンブルなどを自由に調整します。
4. 右側のプレビューエリア（または「◀ 次のページ」「前のページ ▶」ボタン・矢印キー）で仕上がりを確認します。
5. 右上の「印刷・PDF出力」ボタンをクリックし、ブラウザの印刷画面で「PDFに保存」を選択して出力します。
